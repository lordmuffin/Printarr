## Service Dependency Graph

```
Phase 1 (printarr-core)
├── Traefik       ← routes all external HTTPS traffic
└── Tailscale     ← subnet router; exposes LAN to tailnet

Phase 2 (printarr-manyfold)
├── Manyfold      ← DAM; requires PostgreSQL (external) + Redis (local)
└── Redis         ← Manyfold background jobs / ActionCable

Phase 2 (printarr-vault)
├── Makers Vault  ← folder-centric DAM; SQLite
└── oauth2-proxy  ← OIDC gate for Makers Vault

Phase 3 (printarr-slicer)
├── PrusaSlicer   ← headless slicer binary
└── Slicer API    ← FastAPI wrapper; accepts uploads, returns G-code

Phase 4 (printarr-orchestrator)
├── Moonraker     ← Klipper API proxy (connects to RPi over TCP)
└── Spoolman      ← filament tracking; receives webhooks from Moonraker

Phase 4 (printarr-inventory)
└── HomeBox       ← physical inventory; SQLite

Phase 5 (printarr-fleet)
├── OctoEverywhere agent  ← cloud connectivity for Moonraker
└── HomeBox AI sidecar    ← vision model for item auto-tagging
```
